# agenthand — Rust port (PARALLEL EXPERIMENT)

Status as of 2026-10-27. This repo is an experiment next to the
shipped Python product in `~/workspace/agenthand`, which is
untouched and remains the product. The port earns "parity" only
through the gate below; this file says exactly where it stands.

## Verdict

**Parity gate: PASS.** The Rust fidelity core, fed the frozen
verified run's layer/mask/plate, reproduces the frozen receipt
exactly: changed_opaque_pixels = 0 over 580,613 checked opaque
pixels, and the recomposed output's pixel hash is byte-identical
to the frozen composite's. The MCP server runs over stdio with the
same three tool shapes. Live model calls are implemented but were
NOT exercised end-to-end against the Meta API from the Rust binary
(except one inadvertent identify call, see Notes); the gate and
the whole test suite are offline.

## Design choices

- **Hand-rolled JSON-RPC stdio loop, not rmcp.** Deliberate: exact
  wire-shape parity with the Python server (dict results as a text
  content block plus structuredContent; draw's preview as an image
  block; `asset://{asset_id}` resource template) and no SDK
  version skew. The transport is ~150 lines and fully covered by
  the e2e test.
- **Pillow semantics ported from C source** (Resample.c,
  AlphaComposite.c, Convert.c at the 13.0.0 tag): fixed-point
  bicubic coefficients, the 8-bit two-pass resample, premultiplied
  RGBa resize for RGBA inputs, and Pillow's exact
  alpha_composite rounding.
- **SAM codec ported from meta-sam-parser 0.1.0**: base85 with the
  SAM alphabet, the arithmetic range coder, and both payload
  codecs (one_bit context model, lossless predictor model),
  including the canonical re-encode check on one_bit decode.
- **Billing**: reserve/settle JSONL ledger under an exclusive file
  lock, pricing table version `2026-10-26.2` (same as Python),
  $120 default cap under the $150 hard ceiling, unknown models
  refused. Key from `META_API_KEY` (env, or `.env` in cwd / exe
  dir / crate dir — env wins); the value is never printed.
- Subcommands: `serve` (default; the MCP server), `parity <dir>`,
  `verify <source> <final> <mask>` (exit 0/1, port of
  agenthand-verify).

## What is stubbed or missing (blunt)

- **Live end-to-end Rust run: not done.** identify / cut_out /
  draw backends are implemented against `https://api.meta.ai/v1`
  with the same prompts, schemas, projections, and retry rules as
  Python, but no deliberate live call was made from the Rust
  binary; correctness against the live API is unverified. (One
  inadvertent identify call did fire during e2e testing before
  the test's key isolation was fixed — it returned an error body,
  BAD_MODEL_RESPONSE, worst-case cost about a cent of credits.)
- **Ingest gaps vs Python**: no PNG eXIf orientation handling and
  no HEIC (Python gained HEIC via pillow-heif). JPEG EXIF
  orientation is implemented (all 8 transforms).
- **`describe_color_profile` is simplified**: it does not parse
  the ICC description string; profiles are pinned by sha256
  everywhere it matters, and the human-readable label is coarser
  than Python's.
- **`extract_foreground` size mismatch panics** (assert) where
  Python raises ValueError; both hard-fail, different mechanism.
- **PNG encoder output bytes differ from Pillow's** (different
  filter choices). Pixel fidelity is the invariant and is proven;
  file hashes therefore match only for files the Rust side did not
  re-encode — receipts record both file and pixel hashes exactly
  like Python's.
- **Not ported**: the estimator prototype (`measure.py`, a
  parallel lane's WIP, not part of the shipped product), any HTTP
  transport (Python is stdio-first too), OAuth/per-user keys
  (roadmap in both).
- The server has not been registered with a real MCP client
  (only the JSON-RPC e2e driver).
